# AmbieGen
<p align="center">
  <img src="assets/logo.png" alt="AmbieGen Logo" width="300"/>
</p>
**AmbieGen** is a tool for automated testing of autonomous robotic systems. It synthesizes behavior-rich test cases to evaluate perception and decision-making modules of autonomous agents.

---

## Features
- Behavior-based scenario generation
- Evaluation of autonomous decision-making
- Modular and customizable framework
